# Code of Ethics (Advisers Act Rule 204A-1)

Under Rule 204A-1 of the Investment Advisers Act, a registered investment adviser must adopt a written code of ethics that sets standards of business conduct, requires compliance with federal securities laws, and requires access persons to report their personal securities holdings and transactions periodically. The code must also require access persons to obtain pre-approval for certain investments, such as initial public offerings and private placements.
